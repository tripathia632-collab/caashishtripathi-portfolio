# GSTWise Portal Connector (Chrome Extension — Manifest V3)

This companion browser extension bridges **GST Management Software** (`caashishtripathi.in`) with the official **GST Portal** (`https://services.gst.gov.in`) directly inside your Chrome browser—similar to *Express Connector*.

## Security Guarantees
- **Never bypasses CAPTCHA, OTP, EVC, or DSC.** You always complete government authentication yourself.
- **Never persists GST portal passwords** to disk or any remote server.
- Optional login prefill keeps the username and focuses the CAPTCHA box automatically.

## How to Install in Chrome (1-Minute Developer Mode Load)
1. Open Chrome and go to `chrome://extensions/`.
2. Enable **Developer mode** (top-right toggle).
3. Click **Load unpacked** and select this `extension/` folder.
4. Refresh `https://www.caashishtripathi.in/tools/gst-reco/`.
5. The **GST Portal Connector** badge will automatically switch to **Connected (Extension Active)**.
