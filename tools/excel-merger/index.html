How your files stay on your computer

  • No file uploads to a server: Excel and CSV files are read in your browser memory using SheetJS.
  • Local processing: Merging, sorting, duplicate checks and export run inside your browser without sending file contents to a server.
  • Large batches: Supports 2 to 2,000+ files locally, limited only by your device memory.
